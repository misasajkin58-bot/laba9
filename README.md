## Условие задачи
**Вариант 22. Написать программу, выводящую на экран дельтоид, нарисованный с помощью символа, заданного с клавиатуры. Рисуется только контур фигуры. Задаваемые пользователем параметры: радиус R окружности, в которую вписан дельтоид, и сторона a. Остальные параметры фигуры вычисляются.**

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Ввод данных:**
   - Считать символ `symbol`
   - Считать радиус R (целое число от 1 до 20)
   - Считать сторону a (вещественное число)
3. **Проверка параметров:**
   - Если `R < 1`, `R > 20`, `a <= 0` или `a >= 2R` → вывести "Некорректные параметры" и завершить программу
4. **Подготовка поля:**
   - Размер поля: `2R + 1` строк и `4R + 1` столбцов (по горизонтали масштаб ×2, так как символы в консоли вдвое выше своей ширины)
   - Заполнить всё поле пробелами
5. **Вычисление вершин дельтоида** (центр окружности в начале координат):
   - Левая вершина: `(-R; 0)`
   - Правая вершина: `(R; 0)`
   - Верхняя и нижняя вершины: `x = -R + a² / (2R)`, `y = ±a · √(1 - a² / (4R²))`
6. **Цикл по сторонам (k от 0 до 3):**
   - Для каждой стороны взять 300 точек на отрезке между вершинами k и k+1
   - Перевести координаты точки в строку и столбец поля
   - Поставить в эту клетку символ `symbol`
7. **Вывод результата:**
   - Вывести поле построчно
8. **Конец**

## 2. Реализация программы

```c
int TaskDZ() {
    char symbol;
    int R;
    double a;
    char field[41][81];

    printf("Введите символ: ");
    scanf(" %c", &symbol);
    printf("Введите радиус R (1-20): ");
    scanf("%d", &R);
    printf("Введите сторону a (0 < a < 2R): ");
    scanf("%lf", &a);

    if (R < 1 || R > 20 || a <= 0 || a >= 2 * R) {
        printf("Некорректные параметры\n");
        return 1;
    }

    int rows = 2 * R + 1;
    int cols = 4 * R + 1;
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            field[i][j] = ' ';
        }
    }

    double tx = -R + a * a / (2.0 * R);
    double ty = a * sqrt(1 - a * a / (4.0 * R * R));
    double vx[4] = { -R, tx, R, tx };
    double vy[4] = { 0, ty, 0, -ty };

    for (int k = 0; k < 4; k++) {
        int next = (k + 1) % 4;
        for (int s = 0; s <= 300; s++) {
            double t = s / 300.0;
            double x = vx[k] + (vx[next] - vx[k]) * t;
            double y = vy[k] + (vy[next] - vy[k]) * t;
            int row = (int)(R - y + 0.5);
            int col = (int)(2 * (x + R) + 0.5);
            if (row >= 0 && row < rows && col >= 0 && col < cols) {
                field[row][col] = symbol;
            }
        }
    }

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            putchar(field[i][j]);
        }
        putchar('\n');
    }

    return 0;
}
```
